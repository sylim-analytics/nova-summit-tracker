# 🎤 Event Planning Tracker: Hybrid Summit

**One multi-tab tracker that ran a six-hour hybrid summit, from first task to event day.**
Built with **Excel · SharePoint · AI-assisted drafting**.

### 👉 [Try the live demo](https://sylim-analytics.github.io/nova-summit-tracker/)
> Interactive mockup with a fictional event (Nova Summit 2026). No sign-in needed.

## The Challenge
An in-person + Microsoft Teams summit with multiple panels, media support, mid-day room changes, catering, and leadership checkpoints, each owned by different people.

## The Solution
| Tab | What it tracks |
|---|---|
| **Task Tracker** | Category, task, contact, status, due/complete date |
| **Media Services** | Microphones per session, recording, Teams and playback support |
| **Room Layout** | Setup, quantities, placement, mid-day changes |
| **Catering** | Menu sized to RSVPs plus a walk-in allowance; timeline |
| **Run of Show** | Time, agenda item, presenters, emcee cues |

**Plus:** AI-drafted agendas, table tents, and notecards, each reviewed for accuracy before printing.

## Impact
- Coordinated presenters, media services, facilities, and leadership from **one source of truth**
- Supported a **six-hour hybrid event** across in-person and online audiences
